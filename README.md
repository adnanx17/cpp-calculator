# C++ Calculator

A console-based calculator application built using C++. It supports basic arithmetic operations and maintains a history of the last 10 calculations.

## Features

- Perform arithmetic calculations
- Addition, subtraction, multiplication, and division
- Supports advanced mathematical operations
- Input validation
- Stores the last 10 calculations
- View calculation history
- Simple menu-driven interface

## Technologies Used

- C++
- STL Vector
- STL String
- `<cmath>`
- Object-Oriented Programming
